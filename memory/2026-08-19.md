## Findings / Lessons

1. **Shared GH CP OAuth = single point of failure.** One account going empty kills all agents. Every agent needs its own GitHub account + Copilot Max sub.
2. **`openclaw doctor --fix` defaulting to OpenAI** is the new behavior when no valid auth profile exists. Not a bug. Means re-auth is needed via `openclaw models auth login-github-copilot`.
3. **Default Ascendancy Provisioning Key** is not separate — it's the same private key as Bob's bobwebdev-m1 SSH pair. Should be documented and a dedicated provisioning key created.
4. **Port 47022 on systemd-managed SSH** requires a socket override (`/etc/systemd/system/ssh.socket.d/override.conf`), not just sshd_config edits.
5. **Hetzner firewall `ascendancy-firewall-1`** did NOT have port 22 or 47022 open for Vera — only 443 and 18789. Fixed today.
