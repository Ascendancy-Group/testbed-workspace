### Technical Details

**Fast.io CLI syntax:**
```bash
fastio --token "$TOKEN" upload file \
  --workspace "$WORKSPACE_ID" \
  --folder "$FOLDER_ID" \
  /path/to/file.md
```

**Key learning:** Fast.io CLI uses positional arguments for folder names, not `--name` flag:
```bash
# ❌ Wrong
fastio files create-folder --workspace W --name "Folder Name"

# ✅ Right
fastio files create-folder --workspace W "Folder Name"
```
